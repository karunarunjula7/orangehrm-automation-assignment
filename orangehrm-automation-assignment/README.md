# OrangeHRM Automation Assignment

This project automates OrangeHRM functionality using Selenium and Python.

## Project Structure
- 'main.py': Starts the test
- 'pom/': Contains Page Object Model files
- 'tests/': Contains test cases

## How to Run
1. Install dependencies:
bash
pip install -r requirements.txt


## Explanation of Files:
'main.py': This file runs the Selenium automation script (logging into OrangeHRM).

'login_page.py': Defines the login page actions (enter username, password, click login).

'pim_page.py': This file is a placeholder for any future PIM-related automation you might add.

'requirements.txt': Lists the dependencies (selenium).

'README.md': Provides project information and instructions on how to run the automation.

'test_login.py': Placeholder for your future test cases.
